04 • Data structures

Python collections: choose the right container

List

Ordered, changeable collection.

Shopping cart / marks 
marks = [85, 90, 75]
print(marks[0])  # 85
marks.append(95)

Tuple

Ordered, immutable collection.

Fixed record / coordinates 
student = ("Ravi", 21, "ECE")
print(student[0])  # Ravi

Set

Unique elements; no guaranteed order.

Unique registrations 
ids = [101, 102, 101, 103]
print(set(ids))

Dictionary

Key-value mapping.

Phone contacts 
phonebook = {"Ravi": 9876}
print(phonebook["Ravi"])

09 • Algorithms

Algorithm = a repeatable recipe

Problem: Find the highest mark in a list.

Steps

  1. Assume first mark is highest.
  2. Compare each next mark.
  3. Update highest when a larger value appears.
  4. Return the highest value.

Python

marks = [65, 85, 72, 95, 80]
highest = marks[0]

for mark in marks:
    if mark > highest:
        highest = mark

print(highest)  # 95
10 • Searching

Linear search

Classroom analogy: check roll numbers one by one until the target is found.
Python example Run demo
numbers = [10, 20, 30, 40, 50, 60]
target = 40
found = False

for num in numbers:
    if num == target:
        found = True
        break

print("Element found" if found else "Not found")

13 • Big O

Time complexity: how work grows

Big O describes how an algorithm's resource use grows as input size grows. It is not a stopwatch measurement.

O(1) • Constant

Access one list index.

print(items[2])

O(log n) • Logarithmic

Binary search halves the range.

while low <= high:
    mid = (low + high) // 2

O(n) • Linear

Visit each item once.

for item in items:
    print(item)

O(n²) • Quadratic

Compare every pair.

for a in items:
    for b in items:
        compare(a, b)
14 • Compare growth

Same input size, very different work

Illustrative operation-growth comparison for n = 1,000 (log base 2).

O(n log n) is approximately 10,000 growth units here. O(n²) is 1,000,000. This is why algorithm choice matters as data grows.
15 • Space complexity

Memory matters too

Constant extra space • O(1)

numbers = [10, 20, 30]
first = numbers[0]
print(first)

Only a fixed amount of extra working memory.

Linear extra space • O(n)

numbers = [10, 20, 30]
doubled = []

for x in numbers:
    doubled.append(x * 2)

The new list grows with the input.

Challenge 1: second-largest distinct mark

Given marks [45, 90, 65, 80, 95], find the second-largest distinct value.

Python solution Run demo
marks = [45, 90, 65, 80, 95]
unique_marks = sorted(set(marks), reverse=True)

if len(unique_marks) >= 2:
    print(unique_marks[1])
else:
    print("Second largest does not exist")

17 • Live challenge

Challenge 2: count votes

Use a dictionary to count how many votes each candidate received.

Python solution Run demo
votes = ["Ravi", "Kiran", "Ravi",
         "Sneha", "Kiran", "Ravi"]
frequency = {}

for vote in votes:
    if vote in frequency:
        frequency[vote] += 1
    else:
        frequency[vote] = 1

print(frequency)
